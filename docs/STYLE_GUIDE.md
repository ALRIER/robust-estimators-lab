# Visual style guide — current defense app

## Theme
Current audience-facing app uses a dark academic presentation theme.

Core colors:
- Canvas: `#081525`
- Deep panel: `#0d2842`
- Cyan information: `#72cfff`
- Blue: `#58aee8`
- Gold emphasis: `#f3c743`
- Green pass/supported evidence: `#54c786`
- Red fail/negative evidence: `#e66d4f`
- Purple expanded-search / depth evidence: `#a777e3`
- Primary text: `#e9f4ff`
- Secondary text: `#b9c8d9`

## Typography
Use system sans-serif fonts only. Defense views must be readable from a projected screen.

## Layout
- Use the full Streamlit wide layout.
- Prefer one coherent visual story per screen.
- Avoid dense micro-text.
- Keep major numerical claims paired with their meaning.
- Within Stage 5, methodology and results should be visually paired rather than shown as disconnected cards.

## Scientific color meaning
Colors support navigation and evidence status only. They must not imply a scientific claim not present in exported results.

## Simplex views
Every low-dimensional simplex visualization must state that it is a slice of the full 26-dimensional simplex.
